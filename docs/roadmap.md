## المراحل

| المرحلة | المحتوى | متى |
|---|---|---|
| **0. الأساس** | المستودع، Postgres محلي، Prisma، الهوية في Tailwind، تسجيل الدخول والأدوار، CI، الخادم + Coolify، النسخ الاحتياطي | الآن |
| **0.5 صفحة «قريباً»** | ghusn.store: الشعار، العبارة، واتساب والسوشيال، نموذج «أبلغني عند الافتتاح» | فور شراء النطاق |
| **1. النظام الأساسي** | الأقسام والمنتجات، العملات وسعر الصرف، الموردون والشحنات والتكلفة الواصلة، الاستلام والمخزون، الباركود، التسعير المقترح وتنبيه الهامش، نقطة البيع (Offline)، المصاريف، التقارير الأساسية | **قبل افتتاح المحل** |
| **2. المتجر الإلكتروني** | ثنائي اللغة، المناسبات، «صمّم هديتك»، السلة، بنكك + رفع الإشعار، الدفع عند الاستلام، مواعيد التوصيل، حساب العميل، التتبع | بعد 1–2 شهر من التشغيل |
| **3. واتساب API** | قوالب الإشعارات، صندوق الوارد، صورة الهدية، التقييم، التذكيرات | مع المتجر أو بعده |
| **4. التوسعات** | الموارد البشرية والرواتب والسلف، الحسابات الجارية للشركاء، فروقات العملة، تقارير متقدمة | بعد الاستقرار |
| **5. التطبيقات** | Expo: تطبيق العملاء، تطبيق الموظفين والمندوب | عند الحاجة |

## ترتيب البناء داخل المرحلة 1
1. المستخدمون والأدوار (Better Auth: OWNER / MANAGER / STAFF)
2. الأقسام والمنتجات + الصور (Sharp → WebP → R2؛ محلياً مجلد uploads)
3. العملات وشاشة سعر الصرف اليومي
4. الموردون والشحنات + تكاليف الشحنة + التكلفة الواصلة
5. استلام الشحنة، الدفعات، المخزون، طباعة الباركود (TSC TE210، 50×30 مم)
6. التسعير المقترح، لوحة «منتجات تحتاج مراجعة سعر»، سجل الأسعار
7. نقطة البيع (PWA + IndexedDB + مزامنة)
8. المصاريف والتقرير الشهري
