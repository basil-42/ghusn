# هوية غصن البصرية

المرجع المرئي: لوحة «هوية غصن — التصور الكامل» ونموذج «متجر غصن — تصور بالهوية الجديدة» (Artifacts لدى باسل).

## 1. الشعار
- **يُستخدم كما صممه المصمم دون أي تعديل** (بما فيه الضمة فوق الغين). لا يُعاد رسمه ولا كتابته بخط آخر.
- الملفات في `apps/web/public/brand/`:

| الملف | الاستخدام |
|---|---|
| `logo-horizontal-{forest,sage,cream,gold,white}.svg` | الشعار الأساسي: الرمز + «غصن» + GHUSN |
| `logo-vertical-{forest,sage,cream,gold}.svg` | الأكياس، العلب، الغلاف |
| `logo-ar-mark-{forest,cream}.svg` | «غصن» + الرمز (الكلمة في منتصف الإطار) — **رأس الصفحة بالعربي** والأحجام الصغيرة |
| `logo-en-mark-{forest,cream}.svg` | GHUSN + الرمز — **رأس الصفحة بالإنجليزي** |
| `wordmark-ar-{forest,cream}.svg` | «غصن» وحدها |
| `mark-{sage,cream,gold}.svg` | الرمز (إطار + أوراق) |
| `leaves-{sage,cream,forest,gold}.svg` | الأوراق فقط: أيقونة التطبيق، favicon، زخرفة |
| `pattern-{ivory,sage,forest}.svg` | نقشة الأوراق (تكرار) |

- **أقل حجم:** الأفقي الكامل 200px / 40 مم؛ العمودي 120px / 25 مم؛ «غصن» وحدها 64px / 15 مم؛ الرمز 24px / 8 مم. السبب: خطوط GHUSN الرفيعة جداً تختفي تحت هذه الأحجام.
- **المساحة الآمنة:** X = ارتفاع حرف H في GHUSN حول الشعار.
- **ممنوع:** المطّ، التدوير، ألوان خارج اللوحة، الظلال والتأثيرات، الخلفيات المزدحمة أو ضعيفة التباين، التصغير تحت الحد.
- **التركيبات المسموحة:** مريمية/داكن على عاجي، عاجي/ذهبي على داكن، أبيض على مريمية، داكن على رملي.

## 2. الألوان

| التوكن | Hex | الدور | النسبة |
|---|---|---|---|
| `sage` مريمية | `#7D8A6E` | أساسي (من المصمم): خلفيات، شريط علوي، أيقونات | 35% |
| `ivory` عاجي | `#F5F1E8` | خلفية المتجر والمطبوعات | 30% |
| `sand` رملي | `#D1B790` | أساسي (من المصمم): كرافت، شرائط | 15% |
| `forest` أخضر الغابة | `#2F3B2C` | النصوص، الأزرار الرئيسية، العلب الفاخرة | 15% |
| `gold` ذهبي مطفي | `#B08D57` | لمسات فقط: عدّاد السلة، الختم، الفاخر. لا للنصوص الطويلة | 5% |
| `white` | `#FFFFFF` | بطاقات المنتجات | — |

**ألوان وظيفية للواجهة فقط** (لا تُستخدم مع الشعار): `line` `#E4DED1` للحدود والفواصل، `danger` `#A4552F` لرسائل الخطأ.

ملاحظة تباين: نص عاجي على مريمية ضعيف للنصوص الصغيرة؛ استخدم الأخضر الداكن للنصوص والأزرار.

## 3. الخطوط (كلها مجانية OFL)

| الدور | الخط |
|---|---|
| واجهات ونصوص عربية/إنجليزية | IBM Plex Sans Arabic |
| عناوين عربية | Amiri |
| عناوين إنجليزية | Cormorant Garamond |
| لمسة يدوية عربية (بطاقات، شيلات) | Aref Ruqaa |
| لمسة يدوية إنجليزية | Pinyon Script |

خطوط الشعار الأصلية (GE Dinkum، Arsenica Arabic — نسخة تجريبية، Amsterdam Handwriting) **لا تُستخدم في الواجهة** وتحتاج ترخيصاً تجارياً للشعار.

## 4. العبارات
- الأساسية: **هدايا تُصنع لتُذكر** — *Gifts made to be remembered*
- للحملات: **نغلّف المحبة**

دافئة، أنيقة، متقنة، كريمة. عربي بسيط قريب من اللهجة، بلا مبالغة ولا علامات تعجب متكررة.
✓ «طلبك صار جاهز، ومغلّف بعناية. متى يناسبك نوصله؟» ✗ «عرض ناااار 🔥🔥 الحق!!!»

## 6. العناصر
- **«ورقة تكسر الإطار»:** ورقة من الرمز تخرج عن حدود الصورة أو البطاقة — الفكرة المحورية.
- الختم الدائري الذهبي: `GHUSN • GIFTS MADE TO BE REMEMBERED` حول الأوراق.
- نقشة الأوراق للتغليف الداخلي والخلفيات.

## 7. في المتجر (الويب)
- رأس الصفحة: `logo-ar-mark` بالعربي، `logo-en-mark` بالإنجليزي (ارتفاع ~38–50px). الشعار الكامل في التذييل (≥ 220px).
- العناوين Amiri (عربي) / Cormorant Garamond (إنجليزي)، النصوص IBM Plex Sans Arabic.
- الأزرار الرئيسية أخضر داكن؛ الشريط العلوي مريمية؛ البانر الرئيسي داكن مع أوراق شفافة.
- زر تبديل اللغة في الرأس بجانب السلة (`EN` / `ع`).
