# بروفة النظام من الصفر

قائمة تحقق لتجربة غصن كيوم عمل حقيقي قبل الافتتاح (D-141). نفّذها بالترتيب — كل مرحلة تعتمد على ما قبلها. لكل خطوة: ما تفعله، وما يجب أن تراه.

**قبل البدء:** استخدم أرقاماً وأصنافاً حقيقية (شحنة صغيرة فعلية) حتى تكون الأرقام ذات معنى، ودع أختك تنفّذ يوم البيع (المرحلة 6) من هاتفها.

## 0. التصفير

_المنفّذ: باسل — على الماك_

- [ ] `pnpm db:fresh` ثم اكتب «صفر»، وأدخل اسمك ورقمك وكلمة السر عند السؤال  
  ✓ يطبع ✓ النظام فارغ وجاهز، ونسخة احتياطية في مجلد backups/
- [ ] في المتصفح: localhost:3000 ← أدوات المطوّر ← Application ← Clear site data (وفي كل جهاز فُتحت منه نقطة البيع)  
  ✓ لا فواتير قديمة غير مرسلة في نقطة البيع
- [ ] `pnpm dev` ثم الدخول برقمك  
  ✓ الرئيسية فارغة، وشارة «سعر الجنيه لم يُدخل اليوم» ظاهرة

## 1. الضبط

_المنفّذ: باسل_

- [ ] الإعدادات › الضبط › عام: بداية الأسبوع (السبت)  
  ✓ تتغير أزرار «الأسبوع» في الرئيسية بحسبها
- [ ] الضبط › الإيصال: اسم المحل والهاتف والعنوان والعبارة  
  ✓ تظهر في إيصال أول بيع
- [ ] الضبط › نقطة البيع: حد الخصم، مدة المرتجع، محافظ المقبوض  
  ✓ خصم فوق الحد يطلب موافقة لاحقاً
- [ ] الضبط › أقسام المصاريف: إيجار، رواتب، كهرباء وماء، إنترنت، ترحيل، نثريات…  
  ✓ تظهر في نموذج المصروف وفي «المنصرفات» بالرئيسية
- [ ] الضبط › رسائل واتساب والمتجر الإلكتروني: راجع النصوص  
  ✓ النصوص بالعربية وبيانات المحل صحيحة

## 2. المال

_المنفّذ: باسل_

- [ ] سعر الصرف: سعر الجنيه الحقيقي اليوم (السوق الموازي)، واليوان/الجنيه المصري إن ستشتري بهما  
  ✓ الشارة تختفي، وشريط السعر في «المال» يعرضه
- [ ] المحافظ: الرصيد الافتتاحي (جرد) لكل محفظة فيها مال الآن — صندوق المحل، بنكك، حساب باسل – قطر  
  ✓ كشف كل محفظة يبدأ بالرصيد الصحيح
- [ ] التمويل: سجّل تمويلاً منك (ريال) يدخل «حساب باسل – قطر»  
  ✓ المحفظة تزيد، ولا يظهر في المبيعات ولا الربح
- [ ] تحويل بين محفظتين: من حساب باسل إلى بنكك بسعر اليوم  
  ✓ المحفظتان تتغيران بالمبلغين الصحيحين بالعملتين

## 3. المستخدمون والصلاحيات

_المنفّذ: باسل + الأخوات_

- [ ] المستخدمون: حساب «مديرة» وحساب «موظفة» بأرقامهم الحقيقية  
  ✓ كل واحدة تدخل برقمها وكلمة سرها
- [ ] ادخل بحساب الموظفة (نافذة خاصة)  
  ✓ لا ترى التكاليف ولا الهوامش ولا سعر الصرف ولا التقارير
- [ ] ادخل بحساب المديرة  
  ✓ ترى المخزون والطلبات والأسعار، ولا ترى «سعر الصرف للمالك» في الرئيسية

## 4. المشتريات — شحنة حقيقية صغيرة

_المنفّذ: باسل_

- [ ] الموردون: مورد جديد (البلد، العملة، والرصيد الافتتاحي إن كان عليك له مبلغ)  
  ✓ كشف الحساب يبدأ صحيحاً
- [ ] الشحنات › شحنة جديدة: 3–4 بنود، وأنشئ منتجاً جديداً من داخل الشحنة  
  ✓ المنتج يظهر في المنتجات
- [ ] تأكيد الشراء  
  ✓ قيمة البضاعة تظهر في كشف المورد بسعر صرف اليوم
- [ ] المورد › تسجيل دفعة من محفظة  
  ✓ الدين ينقص والمحفظة تنقص؛ «المتاح» يظهر في النموذج
- [ ] تكاليف الشحنة: شحن + جمارك من محفظة  
  ✓ تظهر في الشحنة، وتنقص المحفظة
- [ ] الحالة: في الطريق ← وصلت ← استلام الشحنة  
  ✓ نافذة التأكيد تعرض الكميات والتكلفة الواصلة
- [ ] في الاستلام: اجعل حبة واحدة «تالف» في بند  
  ✓ تكلفة التالف تُحمَّل على السليم من نفس البند
- [ ] أكّد الاستلام  
  ✓ رسالة «استُلمت الشحنة…»، والمخزون يزيد بالسليم فقط

## 5. الأسعار والمنتجات

_المنفّذ: باسل أو المديرة_

- [ ] الأسعار: راجع السعر المقترح لكل صنف (هامش 40%)  
  ✓ السعر مقرّب لأعلى (500 / 1,000 / 5,000)
- [ ] اعتمد الأسعار (أو عدّل واحداً يدوياً)  
  ✓ يُسجَّل في سجل الأسعار وسجل التدقيق
- [ ] المنتج: صورتان، وراجع «جاهزية المتجر»  
  ✓ يظهر في المتجر بصورته وسعره
- [ ] الملصقات: اطبع ملصق باركود لصنف  
  ✓ الماسح في نقطة البيع يقرؤه
- [ ] الأقسام: صورة لقسم واحد  
  ✓ دائرة القسم في المتجر تتغير

## 6. يوم بيع — على هاتف أختك بحساب الموظفة

_المنفّذ: الموظفة_

- [ ] نقطة البيع: فتح وردية بعهدة (مثلاً 50,000)  
  ✓ الوردية مفتوحة باسمها
- [ ] بيع نقداً بالمسح أو البحث، واطبع الإيصال  
  ✓ الإيصال بالعربية وبيانات المحل
- [ ] بيع ببنكك برقم العملية، ثم بيع مختلط (جزء نقد وجزء بنكك)  
  ✓ كل جزء يدخل محفظته
- [ ] بيع برقم هاتف عميل  
  ✓ العميل يظهر في «العملاء» بمشترياته
- [ ] خصم أكبر من الحد  
  ✓ تُطلب موافقة المديرة برقمها وكلمة سرها
- [ ] إلغاء فاتورة قبل إتمامها  
  ✓ نافذة التأكيد، والسلة تُفرَّغ
- [ ] مرتجع: صنف من فاتورة سابقة، ثم استبدال بصنف آخر  
  ✓ المخزون يعود؛ رصيد الاستبدال يُستخدم أو يُرد نقداً
- [ ] مصروف من الدرج (ترحيل)  
  ✓ ينقص النقد المتوقع في الوردية
- [ ] (اختياري) افصل الإنترنت، بع فاتورة، ثم أعد الاتصال  
  ✓ الفاتورة تُرسل تلقائياً ولا تتكرر
- [ ] إغلاق الوردية بعدّ أقل من المتوقع بـ 1,000 وملاحظة  
  ✓ النافذة تعرض المتوقع والمعدود والفرق؛ رسالة «أُغلقت الوردية»

## 7. طلب من المتجر

_المنفّذ: أنت كعميل + المديرة_

- [ ] من هاتف آخر: اطلب منتجاً مع تغليف وبطاقة، والدفع ببنكك  
  ✓ صفحة الشكر والمتابعة، والحجز 24 ساعة
- [ ] ارفع إشعاراً برقم عملية من صفحة المتابعة  
  ✓ جرس الإشعارات عند المديرة
- [ ] الإدارة: ارفض الإشعار مرة بسبب  
  ✓ العميل يرى السبب ويُطلب منه إشعار صحيح
- [ ] ارفع إشعاراً صحيحاً، ثم اعتمد الدفع  
  ✓ الزر لا يعمل قبل خانة «طابقتُ…»؛ المبلغ في محفظة بنكك
- [ ] بدء التجهيز ← جاهز ← سُلِّم لشركة التوصيل ← تم التسليم  
  ✓ المخزون يُخصم عند بدء التجهيز؛ رسالة واتساب جاهزة لكل مرحلة
- [ ] طلب ثانٍ «استلام من المحل» والدفع عند الاستلام  
  ✓ المبلغ يدخل درج الوردية
- [ ] طلب ثالث مدفوع ثم ألغِه  
  ✓ يُسجَّل رد المبلغ من بنكك، والأصناف تعود
- [ ] المحافظ: حوّل من «شركة التوصيل» إلى بنكك  
  ✓ رصيد شركة التوصيل يصير صفراً

## 8. المخزون

_المنفّذ: المديرة + باسل_

- [ ] تسوية مخزون: صنف تالف بسبب  
  ✓ تنتظر موافقتك، ثم يُخصم وتظهر في التقرير
- [ ] جرد: صنفان، الموظفة تعدّ (لا ترى أرقام النظام)، واجعل فرقاً في واحد  
  ✓ المراجعة تعرض الفرق وقيمته
- [ ] اطلب إعادة عدّ، ثم اعتمد  
  ✓ الرصيد يصحَّح ويُسجَّل في سجل التدقيق

## 9. المصاريف

_المنفّذ: المديرة_

- [ ] مصروف إيجار من صندوق المحل بصورة الفاتورة  
  ✓ يظهر في المصاريف و«المنصرفات»
- [ ] ألغِ مصروفاً بسبب  
  ✓ نافذة التأكيد؛ المبلغ يعود للمحفظة

## 10. المراجعة — هل الأرقام منطقية؟

_المنفّذ: باسل_

- [ ] الرئيسية: صافي المبيعات، مجمل الربح، المنصرفات، صافي الربح التقريبي  
  ✓ تطابق ما بعته وصرفته فعلاً
- [ ] أرصدة المحافظ  
  ✓ تطابق حسابك اليدوي على ورقة
- [ ] التقارير: الشهري، النقد، الشحنات، الخصومات  
  ✓ لا أرقام غريبة أو سالبة بلا سبب
- [ ] سجل التدقيق  
  ✓ كل عملية أعلاه مسجّلة بمن فعلها ومتى
- [ ] المخزون: الكميات والتكلفة  
  ✓ تساوي المستلم − المباع + المرتجع ± التسويات
